Recommended Verification Route

One proportional pass, one bounded repair, then a visible stop for user choice instead of an automatic loop.

  1. PendingA real feature change requires fresh evidence.
  2. VerifyUse the smallest relevant command and real user journey.
  3. Repair onceFix one observed product issue and rerun stale checks.
  4. BlockerDetect login, access, credentials, browser, or environment failure.
  5. User choiceLogin, continue without browser, stop, or type another instruction.
  6. ResumeContinue only after explicit approval; preserve the browser session.
  7. PassedReport only fresh, observed evidence.
